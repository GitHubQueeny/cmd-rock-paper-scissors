# cmd-rock-paper-scissors
Rock, Paper, Scissors for CMD

Moin!

This is a batch file I wrote during the COVID-19 pandemic: a Rock, Paper, Scissors game that runs directly in the Windows Command Prompt (cmd).

You can play it at school during a break, or use it to impress friends who aren't into computer science and show them what's possible with nothing more than the Windows command line.

How to play
Download the .bat file.
Double-click it, or run it from cmd.
Choose your move by entering a number and pressing Enter:
1 = Rock
2 = Paper
3 = Scissors
See if you can beat the computer!
Planned features

When I find the time, I might add the following:

An English version of the game (it is currently only available in German)
A better algorithm for the computer's moves to make the game feel more realistic
